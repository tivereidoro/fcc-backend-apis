# freeCodeCamp — Backend Development and APIs Course

Certification labs of the
[FreeCodeCamp Backend Development and APIs](https://www.freecodecamp.org/learn/back-end-development-and-apis-v9/)
certification.

| Lab | Focus | Port |
| --- | --- | --- |
| [`build-a-prime-number-checker-module`](build-a-prime-number-checker-module) | Building and exporting an npm module | — |
| [`build-a-timestamp-microservice`](build-a-timestamp-microservice) | REST API and date parsing | 8000 |
| [`build-a-personal-profile-app`](build-a-personal-profile-app) | Express routing and JSON responses | 3000 |
| [`build-a-data-sanitizer`](build-a-data-sanitizer) | Custom Express middleware | 3000 |
| [`build-a-chat-app`](build-a-chat-app) | Real-time WebSockets | 3001 |
| [`build-a-family-movie-watchlist-api`](build-a-family-movie-watchlist-api) | JWT authentication and role-based authorization | 3000 |

## Notes

- `build-a-family-movie-watchlist-api` needs a `.env` file. Copy
  `.env.example` to `.env` and set your own `JWT_SECRET`.
- The seeded data under `build-a-family-movie-watchlist-api/data/` is the
  fixture data provided by the course.
